# SWAG LABS - REQUIREMENTS


## 1. INTRODUCTION:
Swag Labs is an e-commerce web application designed to simulate an online shopping experience. 
The application allows users to log in, browse products, view products details, add products to shopping cart, proceed through the checkout process, and complete an order. This project focuses on manually testing the application's main functional and user-facing features.


## 2. APPLICATION SCOPE:
This project focuses on manually testing the main functional features on Swag Labs application.

### In Scope: 
The following areas will be covered during testing:
- User login and authentication.
- Login validation and error messages.
- Product catalog and product information.
- Product sorting functionality.
- Product details.
- Adding and removing products from the shopping cart.
- Shopping cart functionality.
- Checkout information and validation.
- Order overview and order completion.
- Order confirmation.
- Navigation and menu functionality.
- Logout functionality.
- Reset app functionality.
- UI elements related to the above features.

### Out of scope:
- API testing.
- Database testing.
- Performance and load testing.
- Security penetration testing.
- Code testing.
- Mobile application testing.
- Accessibility testing as a dedicated testing activity.
- Extensive cross-browser compatibility testing.w
